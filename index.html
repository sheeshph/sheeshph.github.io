Sheesh Analytics

Sheesh Analytics is a private, personal tool used by the owner of the YouTube channel sheesh. (@sheeshph) to read that channel's own performance data, such as views, watch time and subscriber changes, through the official YouTube Data API and YouTube Analytics API.

The tool requests read-only access. It cannot upload, edit or delete videos, comments or any other content. It is not offered to the public and is used only by the channel owner.
