Privacy Policy

Last updated: October 23, 2026

What this app is

Sheesh Analytics is a personal tool used only by the owner of the YouTube channel sheesh. (@sheeshph) to view that channel's own analytics.

What data it accesses

With the owner's permission, the app uses Google OAuth to request read-only access to:

  • YouTube Data API (youtube.readonly): channel and video details such as titles and public statistics.
  • YouTube Analytics API (yt-analytics.readonly): channel and video performance metrics such as views, watch time and subscriber changes.

How the data is used and stored

Data is retrieved on request and shown to the channel owner only. Authorization credentials are stored locally on the owner's own computer. The app does not sell, share or transfer any data to third parties, and does not use it for advertising.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from your Google Account at myaccount.google.com/permissions.
